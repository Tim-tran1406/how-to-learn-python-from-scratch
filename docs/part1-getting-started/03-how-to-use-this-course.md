# 3. How to use this course

[:material-rocket-launch: Open the Colab Playground](https://colab.research.google.com/github/Tim-tran1406/how-to-learn-python-from-scratch/blob/main/notebooks/playground.ipynb){ .md-button target=_blank }

A quick guide to getting the most out of these lessons.

## The loop that actually works

For every example you see:

1. **Read** the explanation.
2. **Run** the code (paste it into the [Colab Playground](https://colab.research.google.com/github/Tim-tran1406/how-to-learn-python-from-scratch/blob/main/notebooks/playground.ipynb){ target=_blank } and press ▶).
3. **Change** something and run it again — predict what will happen *first*, then check.

!!! tip "Predict, then run"
    Before you run an example, guess the output in your head. When you're right, it confirms you
    understand. When you're wrong, you've just found a gap — that's a *good* thing.

## Things you'll see in the lessons

**Code blocks** — copy them with the copy button in the top-right corner:

```python

```

**Expected output** is shown like this:

```text
Copy me with the button →
```

**Helpful callouts:**

!!! note "Note"
    Extra context that's good to know.

!!! tip "Tip"
    A shortcut or best practice.

!!! warning "Watch out"
    A common mistake to avoid.

## How the course is organized

We go in order, from the absolute basics to advanced topics. Each part builds on the previous
one, so it's best to follow along top to bottom. See the **[Roadmap](../roadmap.md)** for the
full list.

## A note on pace

There's no rush. It's far better to **truly understand** a small thing and be able to use it than
to skim ten things. If a concept doesn't click, run the examples a few times and tweak them — it
will.

## Recap

- Read → Run → Change, for every example.
- Predict outputs before running.
- Go in order; take your time.
