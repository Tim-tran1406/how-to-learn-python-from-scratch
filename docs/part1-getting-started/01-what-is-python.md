**In one sentence:** Python is a **programming language** — a way to give a computer
instructions using text that reads almost like English.

## Why a "language"?

A computer only understands very low-level signals. A programming language lets *you* write
instructions in a form *you* can read, which the computer then carries out. Python is famous for
being one of the **most readable** languages — which is exactly why it's the world's most popular
first language.

Here's a complete, working Python program:

```python
print("Hello, world!")
```

When you run it, the computer prints:

```text
Hello, world!
```

That's it — one readable line. Many other languages need several lines of setup to do the same
thing. That readability is Python's superpower.

## A few facts worth knowing

- **Created by** Guido van Rossum and first released in **1991**.
- **Named after** the comedy group *Monty Python* — not the snake. 🐍
- **Interpreted:** Python runs your code line by line, so you can try things instantly without a
  separate "compile" step.
- **Dynamically typed:** you don't have to declare what kind of value a variable holds — Python
  figures it out (more on this soon).
- **Free and open source.**

!!! warning "Python 2 vs Python 3 — always use Python 3"
    You may see old tutorials using **Python 2**. It was officially retired on **January 1,
    2020** and should not be used. This course uses **Python 3** (the current line), which is
    what everyone uses today.

## What is Python used for?

Python is a generalist — it shows up almost everywhere:

| Area | Examples |
|------|----------|
| **Data science & AI** | pandas, NumPy, scikit-learn, PyTorch |
| **Web development** | Django, Flask, FastAPI |
| **Automation / scripting** | renaming files, scraping websites, sending emails |
| **Anything else** | games, finance, science, hardware… |

!!! tip "Why this matters for you"
    Because Python is used in so many fields, the time you invest learning it pays off no matter
    which direction you go — data, web, automation, or AI.

## Recap

- Python is a **readable programming language** for telling computers what to do.
- It's **interpreted** and **dynamically typed**, which makes it beginner-friendly.
- Always use **Python 3**.
- It's used across data, web, automation, AI, and more.
