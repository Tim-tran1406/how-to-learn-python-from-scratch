# How to Learn Python from Scratch

Welcome! This is a **free, beginner-friendly guide to mastering Python** — written in plain
English, packed with examples you can run, and fact-checked against the
[official Python documentation](https://docs.python.org/3/) and the most respected Python books.

No prior programming experience needed. You'll go from *"what is Python?"* all the way to
advanced topics like decorators, generators, and async.

## How this course works

- :material-book-open-variant: **Read on this website** — with search, dark mode, and one-click
  copy on every code block.
- :material-rocket-launch: **Run it live** — open the free
  [Python Playground on Google Colab](https://colab.research.google.com/github/Tim-tran1406/how-to-learn-python-from-scratch/blob/main/notebooks/playground.ipynb){ target=_blank }
  (no installation needed), paste any example, and press ▶.
- :material-lightbulb-on: **Learn by doing** — each lesson explains one idea simply, then shows
  it with an example you can run and tweak yourself.

!!! tip "The golden rule of learning to code"
    Don't just read the examples — **run them, then change something and see what happens.**
    Breaking things on purpose is the fastest way to understand how they work.

## What you'll learn

1. **Getting Started** — what Python is, installing it, your first program
2. **Basics** — variables, numbers, strings, booleans, input/output
3. **Control Flow** — `if`/`else`, loops
4. **Data Structures** — lists, tuples, dictionaries, sets, comprehensions
5. **Functions** — arguments, scope, lambdas, `*args`/`**kwargs`
6. **Files & Errors** — reading/writing files, exceptions
7. **Object-Oriented Programming** — classes, inheritance, dunder methods
8. **Intermediate** — modules, the standard library, iterators, generators, decorators
9. **Advanced** — type hints, regex, concurrency, testing, performance
10. **Pythonic Practices** — PEP 8, idioms, where to go next

See the [Roadmap](roadmap.md) for the full chapter list.
